# Tassie's World

Portfolio of Taseyana Booker-Hopkins. A static site: `index.html` plus the `images` and `videos` folders and `resume.pdf`. No build step.

To update: edit the lists near the top of the `<script>` in `index.html` (PROJECTS, DESIGNS, VIDEOS, etc.), then upload the changed files.

Note: the visitor book saves notes directly only inside Claude. On any other host it opens an email to Tassie instead.
